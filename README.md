# Python Calculator

A simple Python calculator project created for UCS 745 Cloud and DevOps Lab (Q1).

## Usage

```bash
python calc.py
```

## Function

`calculate(a, b)` — currently returns `a + b`.

## Branches

| Branch            | Behaviour            |
|-------------------|----------------------|
| `main`            | `a + b` (initial)    |
| `feature-multiply`| `a * b`              |
| `feature-subtract`| `a - b`              |
